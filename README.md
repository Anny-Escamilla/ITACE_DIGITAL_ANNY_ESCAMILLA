# ITACE Digital Anny Escamilla

> Propuesta académica **no oficial**. No representa el sitio oficial del ITACE.

## Descripción
Modernización de mi página anterior del ITACE Reynosa, convertida en un sitio
institucional moderno, funcional, atractivo y preparado tecnicamente para su 
publicacion.

## Objetivo
Diseñar, desarrollar y publicar una propuesta de portal institucional aplicando
HTML5, CSS y JavaScript, como proyecto del modulo de programacion.

## Tecnologías utilizadas
- HTML5
- CSS
- JavaScript
- JSON
- Git y GitHub Pages

## Funcionalidades
- Navegación por secciones
- Diseño adaptable a celulares, tabletas y computadoras
- (Pendiente) Directorio docente con búsqueda y filtros

- Galería multimedia
